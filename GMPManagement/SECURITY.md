# Security policy

## Supported versions

This is a personal research project. Security fixes are considered for the
latest published revision only.

## Reporting a vulnerability

Please do not open a public issue for a suspected credential leak or other
security vulnerability. Contact the repository owner privately through the
security contact configured on the GitHub repository.

When reporting an issue, include:

- the affected file or component;
- reproducible steps or a minimal proof of concept;
- the potential impact;
- any suggested mitigation.

Never include real API keys, tokens, passwords, or other secrets in an issue,
pull request, or support request.
